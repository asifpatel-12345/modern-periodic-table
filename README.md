# ⚛️ PeriodicX — Modern Interactive Periodic Table

An interactive and modern Periodic Table of Elements built using HTML, CSS, and JavaScript. Explore all 118 chemical elements through a beautiful, responsive interface with element information and images.

## ✨ Features

- 🧪 **118 Chemical Elements** — Explore the elements of the periodic table.
- 🎨 **Modern UI** — Dark theme, vibrant category colors, and smooth hover effects.
- 🔍 **Live Search** — Search by element name, chemical symbol, or atomic number.
- 🖼️ **Element Images** — View element images when available.
- 📚 **Element Information** — Discover atomic number, atomic mass, category, period, and group.
- 🖱️ **Interactive Experience** — Hover over or click an element to explore it.
- 📱 **Responsive Design** — Designed to work on desktop and mobile screens.
- 🌐 **Wikipedia Integration** — Load additional information and images from Wikipedia.

## 🛠️ Technologies Used

- CSS3

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/modern-periodic-table.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Make sure you have an internet connection for external element images and information.

Alternatively, open `index.html` directly in your browser.
